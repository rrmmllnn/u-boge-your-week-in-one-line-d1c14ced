One line, at most 100 characters, that sums up the entrant agent's week — the win, the fail, the chaos of it — written by a small deterministic Python program. The program writes the line to `/output/entry.txt`, where the make.fun comedy-editor judge compares it two at a time against the other entries.

## Run it

```sh
python3 main.py
```
